# Golden Files

Hier liegen Testfälle aus echten, anonymisierten Forderungsaufstellungen, je Modul in einem eigenen Ordner (`verbindlichkeiten/`). Format und Beispiel: [Fachkonzept, Kapitel 12](../../../docs/fachkonzept.md#12-qualitätssicherung).

Regeln aus [CLAUDE.md](../../../CLAUDE.md):

- Erwartungswerte stammen aus der Aufstellung des Gläubigers oder aus manueller Prüfung, nie aus dem Programm selbst.
- Erwartungswerte ändern ausschließlich Menschen.
- Schlägt ein Fall fehl, wird der Code korrigiert, nicht die Erwartung.
- Keine personenbezogenen Daten: keine Namen, Anschriften, Aktenzeichen oder IBANs.
